# DSA Teaching Workspace

For DSA lessons, problem review, new course problems, or progress updates, read `master/docs/WORKFLOW.md` before acting. Ground teaching in `master/docs/MISSION.md`, learner preferences in `master/docs/NOTES.md`, and current state in `master/docs/PROGRESS.md`.

Treat the numeric directories under `master/course/arrays/` as the authoritative course order. Preserve the learner's submitted solution and attempts; place later attempts in the problem's `attempts/` directory.

Use `master/templates/` when adding problem documentation. Put reusable algorithm knowledge in `master/patterns/` and problem-specific reasoning in that problem's `explanation.md`.
