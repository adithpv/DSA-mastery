# DSA Master Course

This is the main teaching workspace. It keeps course order, solutions, explanations, reusable patterns, and review state separate so both the learner and an agent can quickly find the right context.

## Start Here

1. Open [`docs/PROGRESS.md`](docs/PROGRESS.md) and choose the next numbered problem or a problem due for review.
2. Read only that problem's `prompt.md`.
3. Solve it in `solution.js`, or create a dated file in `attempts/` when revisiting it.
4. Ask the agent to review the attempt using [`docs/WORKFLOW.md`](docs/WORKFLOW.md).
5. Explain the pattern and invariant from memory before opening `explanation.md`.

## Course

- [`course/foundations/`](course/foundations/README.md) — loops, scans, digit manipulation, and pattern-printing practice.
- [`course/arrays/`](course/arrays/README.md) — the active course. Its `01`, `02`, `03` ordering is authoritative.

## Learning System

- [`docs/`](docs/) — mission, resources, teaching preferences, workflow, and progress.
- [`lessons/`](lessons/README.md) — interactive visual explanation for every numbered problem.
- [`patterns/`](patterns/README.md) — reusable ways to recognize and solve families of problems.
- [`learning-records/`](learning-records/) — demonstrated learning that should influence future lessons.
- [`notes/`](notes/) — longer supporting notes.
- [`templates/`](templates/) — canonical files for adding a problem.

The original solutions were moved into the course without rewriting their content.
