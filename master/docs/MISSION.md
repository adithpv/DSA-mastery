# Mission: DSA Array Patterns

## Why
You are learning DSA so you can understand common LeetCode-style array problems clearly, write the algorithm yourself, and return later to revise without starting from zero.

## Success looks like
- Explain why an array algorithm works before writing code.
- Trace pointer movement step by step on a sample input.
- Recognize when a problem needs in-place updates and constant extra space.
- Write JavaScript and Java versions of common array solutions.

## Constraints
- Explanations should be beginner-friendly and tied to the files in this repo.
- Prefer short examples, comments in code, and quick reference notes.
- Avoid jumping into advanced variants before the base pattern is clear.

## Out of scope
- Advanced dynamic programming and graph algorithms for now.
- Heavy math proofs unless needed for a specific problem.
