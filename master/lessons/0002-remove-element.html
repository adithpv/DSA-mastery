Remove Element

Read everything. Write only what survives. The write pointer is the size of your answer so far.

Pointer jobs

  • i examines every original value.
  • x points to the next free output position.
  • Write and increment only when the value should stay.

The invariant

Before each read, nums[0...x-1] contains exactly the accepted values seen so far, in their original order.

Skipping leaves the prefix correct. Writing one accepted value extends it correctly.

The algorithm

let x = 0;

for (let i = 0; i < nums.length; i++) {
    if (nums[i] !== val) {
        nums[x] = nums[i];
        x++;
    }
}
return x;

What to remember

Here x is already a count. It is the next empty position and increases once per kept value. Do not add one.

O(n) timeOne decision per value.
O(1) spaceWrites happen in the input.

Check your memory

What does x mean?

It is the next write position and the number of accepted values already written.

Why can writing forward not destroy unread data?

The write pointer never moves ahead of the read pointer, so it writes only into positions already read or the current position.
