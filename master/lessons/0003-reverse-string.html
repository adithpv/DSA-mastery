Pattern · Converging two pointers

Reverse String

The first belongs where the last is. Swap symmetric pairs, then shrink the unfinished middle.

💡
Recognition signal
When a task is symmetric across both ends—reverse, compare, pair—think: left and right pointers moving inward.

The picture

adith
left = 0 →← right = 4

Swap the outside pair. After that, those two positions are finished forever.

Pointer jobs

  • left marks the first unfinished position.
  • right marks the last unfinished position.
  • Each swap fixes two final positions.

Walk it: [a, d, i, t, h]

Swap the outside pair

adith

Save a, put h on the left, then put the saved a on the right.

The outside is final

hdita

Move inward. Only the interval from index 1 to 3 remains unfinished.

Swap the next pair

htida

The middle character has no partner and stays where it is.

Pointers meet → finished

htida

Once left is no longer less than right, every pair has been handled.

The invariant

Before every swap, everything outside [left, right] is already in its final reversed position. Only the inside interval remains.

This makes stopping at the middle safe.

The algorithm

let left = 0;
let right = s.length - 1;

while (left < right) {
    let temp = s[left];
    s[left] = s[right];
    s[right] = temp;
    left++;
    right--;
}

What to remember

Save before overwriting. Without a temporary variable, the original left character is lost before it can move right.

O(n) timeAbout half of n swaps.
O(1) spaceOnly pointers and one temporary value.

Primary source: LeetCode 344. Pattern reference: Converging two pointers.

Check your memory

Why use left < right?

When pointers meet, the middle value is already correct. After they cross, every pair has been swapped.

How many swaps for length 6?

Three swaps: positions 0↔5, 1↔4, and 2↔3.
