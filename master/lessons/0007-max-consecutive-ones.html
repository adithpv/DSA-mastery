Max Consecutive Ones

A one extends the streak ending here. A zero breaks it. Keep the current run separate from the best run ever seen.

💡
Recognition signal
The word “consecutive” means continuity matters. Track a current streak that resets when the condition fails.

State jobs

  • count is the streak ending at the current position.
  • maxCount is the best streak found anywhere so far.
  • A zero resets only count, never the saved best.

The invariant

After each value, count is the length of the all-ones streak ending there, and max(maxCount, count) is the longest streak in the scanned prefix.

The ending-at-current meaning tells you exactly when to increment and reset.

The algorithm

let count = 0;
let maxCount = 0;

for (const value of nums) {
    if (value === 1) {
        count++;
    } else {
        maxCount = Math.max(maxCount, count);
        count = 0;
    }
}
return Math.max(count, maxCount);

What to remember

The end-of-array trap: if the longest streak reaches the last value, no zero arrives to save it. Compare count again when returning.

O(n) timeOne update per bit.
O(1) spaceTwo counters only.

Check your memory

Why does zero reset count?

A streak ending before the zero cannot continue through it, so a later one begins a new streak.

Why not count all the ones?

The question asks for adjacent ones; total count ignores the zeroes that divide separate runs.
